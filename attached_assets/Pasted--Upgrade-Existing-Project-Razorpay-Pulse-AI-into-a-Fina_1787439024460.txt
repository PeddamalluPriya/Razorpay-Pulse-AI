# Upgrade Existing Project: Razorpay Pulse AI into a Financial Intelligence Copilot

Do NOT rebuild the project from scratch.

Transform the existing Razorpay Pulse AI into a premium fintech AI product while preserving deployment, existing APIs, and current dashboard functionality where possible.

The finished product should feel like something Razorpay could genuinely launch—not a student dashboard.

Use modern UX inspired by Razorpay, PhonePe, Google Pay, and Linear.

---

## Product Identity

Product Name:

# Razorpay Pulse AI

Subtitle:

**Your Financial Intelligence Copilot**

Hero text:

> Import your payment history. Let AI explain where your money went, detect hidden spending patterns, and generate actionable financial insights in seconds.

The design should immediately communicate trust.

Use:

* deep navy background
* Razorpay blue accents
* white typography
* glassmorphism cards
* soft gradients
* smooth animations

Avoid flashy colors.

---

The experience should feel effortless.

# Feature 1 — Beautiful Import Experience

This replaces a plain upload screen.

Create four large import cards.

* Import PhonePe Statement
* Import Google Pay Statement
* Import Razorpay Merchant CSV
* Try Demo Data

Important:

Do NOT ask users for credentials or OTP.

Instead, simulate the experience by accepting exported transaction statements or instantly loading realistic demo data.

Add drag-and-drop upload with animated hover effects.

---

# Feature 2 — PhonePe-style Transaction Feed

Instead of showing charts first...

Show a familiar payment history.

Each transaction should have:

* merchant logo placeholder
* merchant name
* UPI/card label
* date
* amount
* status
* category icon

Example merchants:

* Swiggy
* Zomato
* Blinkit
* Uber
* Amazon
* Starbucks
* Salary Credit

The transaction feed should look like a real fintech app.

Allow search and filtering.

# Feature 3 — AI Financial Summary (Main Wow Moment)

After importing data, generate a conversational AI summary.

Example:

> You spent ₹18,420 this month.

> Food delivery accounted for 32%.

> Weekend spending was 46% higher than weekdays.

> Your largest recurring expense is subscriptions.

> Estimated monthly savings opportunity: ₹2,300.

The summary should feel written by an intelligent financial assistant—not a template.

Use the existing LLM integration.

# Feature 4 — Ask My Money (AI Chat)

Add a floating AI assistant.

Users can ask:

* Where did my salary go?
* How much did I spend on coffee?
* Why did this month cost more?
* Which merchant do I pay most often?
* How many UPI payments failed?

The assistant should answer using uploaded transaction data.

Include quick suggestion chips.

Responses should feel conversational.
